# VELORE Atelier — Interior Architecture & Design

> Private-client interior architecture and bespoke joinery based in Malappuram, Kerala, executing commissions across South India and international private residences.

## Overview
VELORE is an editorial luxury interior architecture web experience featuring:
- **Scroll-Driven Cinema Engine**: Full-screen high-definition architectural video reveal scrubbing seamlessly on scroll.
- **Editorial Brand Story**: Narrative monograph with founder statement and core values.
- **Interactive Portfolio**: Before/after interactive comparison sliders and typology filtering.
- **Spaces in 360°**: Panoramic room walkthroughs with day/night ambient lighting scene toggles.
- **Six Quiet Phases**: Complete architectural methodology timeline from laser survey to turnkey handover.
- **Materials & Studio Editions**: Curated signature pieces, material provenance swatches, and inside-the-studio craftsmanship.
- **Private Consultation Concierge**: Multi-step client brief and consultation booking.

## Structure
- `index.html` — Semantic, accessible HTML5 structure with responsive layouts.
- `styles.css` — Custom editorial luxury CSS with warm ambient palettes and fluid typography.
- `script.js` — GSAP & ScrollTrigger animations, smooth scrub engine, and interactive components.
- `assets/` — High-definition video monographs and curated photography.

## Getting Started
Open `index.html` directly in any modern web browser, or serve locally on port 5500:
```bash
# Launch local server
http://localhost:5500/
```
